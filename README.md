# МикроТест Вижн

Веб-программа для лабораторных фото чашек Петри. Три блока:
- **F:1 Антибиотикорезистентность** – работает (описание ниже);
- **F:2 Подсчёт колоний на чашках Петри** – в разработке;
- **F:3 Определение площади культур** – в разработке.

Работа хранится по **датасетам** – отдельным наборам чашек (например, для каждой лаборатории), с категориями и своим порядком.

## F:1 Антибиотикорезистентность
Измерение зон подавления роста (диско-диффузионный метод) по фото чашки Петри.
Программа находит диски с антибиотиком, измеряет диаметр зоны вокруг каждого в миллиметрах
и ставит категорию S / I / R по таблицам «Российских рекомендаций» (МАКМАХ 2024-02, по EUCAST).

**Открыть:** https://grom1143.github.io/zona/

## Как это работает
- Всё считается в браузере: фото никуда не отправляются.
- Масштаб – по стандартному диску 6 мм, края зон – по 96 лучам от каждого диска.
- Нейросеть не используется, только классическая обработка изображения.
- Результаты можно поправить вручную (линейка, гибкий контур), выгрузить в Excel, сохранить проект в файл.
- Работа сама сохраняется в браузере; любое действие, включая удаление чашки, можно отменить.
- Если фото снято под углом (диски вытянуты), программа предупреждает.

## Приложение для Android
**Скачать:** https://grom1143.github.io/zona/app/MikroTest-Petri.apk (≈ 2 МБ, Android 7 и новее).

1. Откройте ссылку на телефоне, скачайте файл.
2. Откройте скачанный `MikroTest-Petri.apk`; телефон попросит разрешить установку из этого источника (браузера или «Файлов») – разрешите.
3. На экране появится «МикроТест» с лягушкой.

Приложение – оболочка вокруг упрощённой версии для телефона (Trusted Web Activity, папка `phone/`): открывает https://grom1143.github.io/zona/phone/ на весь экран через Chrome.
На сайте с телефона теперь открывается обычная версия; `phone/` оставлена для приложения.
Поэтому **правки сайта появляются в приложении сами**, переустанавливать не нужно; без интернета работает сохранённая версия.
На iPhone APK не ставится – там сайт добавляется на экран «Домой» через «Поделиться».

## Файлы
| Файл | Что внутри |
|---|---|
Код подключается по порядку – каждый следующий файл пользуется объявленным в предыдущих.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы: блоки F:1–F:3, страница датасетов, шапка, окно с фото, инструменты, таблица, окна |
| `style.css` | оформление: светлая и тёмная тема, страницы выбора, рабочий экран, режим «Во весь экран» |
| `analysis.js` | анализ изображения без интерфейса: диски, масштаб, края зон, колонии, цветные диски, пример чашки (`analyze`) |
| `core.js` | основа: состояние, геометрия зон, загрузка и обрезка фото, отмена, сохранение в браузере, файл проекта |
| `home.js` | страницы выбора: блоки F:1–F:3, датасеты (обложки, разметка, прогресс), категории и палитра, порядок, адреса `#m=` / `#ds=` |
| `f1.js` | блок F:1: категории S / I / R, антибиотики, таблица и Excel, разметка мышью и пальцем, кнопки, редактор снимка, запуск |
| `logo.js` | анимация логотипа по нажатию |
| `vendor/xlsx.full.min.js` | SheetJS – создание файлов Excel |

## Важно
- **Исследовательский и учебный инструмент, не для клинической диагностики.**
  Каждый результат проверяет человек; точность на реальных фото ещё измеряется.
- Пороги S / I / R пересматриваются ежегодно – сверяйте с актуальной версией рекомендаций.
